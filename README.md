## Proyectos destacados

### [OfferTrack‑M82](https://github.com/OyasumiDev/OfferTrack-M82) · Plataforma de búsqueda laboral asistida por IA

**Go · TypeScript · Node.js · Express · Playwright · Qdrant · Docker**

Plataforma modular para recopilar, normalizar y analizar vacantes de empleo. Integra scraping web, embeddings locales, almacenamiento vectorial e IA generativa para evaluar compatibilidad y adaptar currículums a oportunidades específicas.

* Diseñé un núcleo en **Go** con separación entre dominio, servicios, configuración, CLI, proveedores de IA y almacenamiento.
* Implementé un servicio REST en **TypeScript/Express** para scraping de portales, normalización de vacantes y generación de embeddings.
* Integré **Playwright** y **Cheerio** para procesar portales web con contenido dinámico y HTML estático.
* Implementé una abstracción de proveedores de IA para trabajar con **Gemini, Claude, Groq, OpenRouter y Ollama**.
* Utilicé **Qdrant** para almacenar vectores y habilitar procesamiento semántico de vacantes, perfiles y CVs.
* Configuré contenedores con **Docker Compose** e integración continua con **GitHub Actions** para linting, compilación y pruebas.
